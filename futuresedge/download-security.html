Windows download security

CapitalGuildX publishes FuturesEdge Mini. Version 1.3.1 identifies CapitalGuildX in Windows file metadata. This installer does not yet have an Authenticode signature, so Windows cannot verify the publisher from the file.

Verify your download

  1. Use the official FuturesEdge Mini download page.
  2. In PowerShell, run this command with the full path to the file you downloaded.
Get-FileHash -Algorithm SHA256 -LiteralPath "C:\path\FuturesEdge_Mini_Setup.exe"

Compare the result with the release manifest. A match confirms the download matches the official release bytes. If your browser or Windows displays a security warning, keep its protections enabled and contact support. You can keep using the online calculator while we investigate.

What the installer does

Setup runs under your Windows account, installs the trading calculator and journal, and creates the shortcuts you select. Uninstall keeps your settings and journal in your Windows profile. See the privacy policy for local storage and optional cloud sync.

Report a warning

Email capitalguildx@gmail.com with the exact warning, browser version, Windows version and download URL. A screenshot is useful if it excludes your account and trading details.
